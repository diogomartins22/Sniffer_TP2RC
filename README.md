# Sniffer_TP2RC
----------Redes de Computadores---------- 
Trabalho Prático 2 — Desenvolvimento de um Packet Sniffer e Analisador de tráfego

DESCRIÇÃO: 
Sniffer em python com comportamento baseado em Wireshark.

DEPENDÊNCIAS (Bibliotecas): 
Para executar o programa, é necessario instalar:
 - Python 3
 - Scapy

Nota: será necessário ter permissões a nível de Administrador/Root para a captura de pacotes numa interface real.

Nota: para verificar todos as opcoes possiveis executa o comando:

```
sudo python3 main.py --help
```
